# Guide de Démarrage Rapide - Culture Média News

## 🚀 Lancer le Site Localement

### Étape 1 : Ouvrir un terminal

### Étape 2 : Naviguer vers le dossier
```bash
cd "/Users/studiojls/.gemini/antigravity/scratch/CULTURE MEDIA"
```

### Étape 3 : Lancer le serveur
```bash
python3 -m http.server 8080
```

### Étape 4 : Ouvrir dans le navigateur
Ouvrir cette URL : **http://localhost:8080/index.html**

---

## 🎨 Tester le Switch de Thèmes

1. Une fois la page chargée, cherchez le **bouton jaune rond** en bas à gauche avec l'icône palette 🎨
2. Cliquez dessus pour ouvrir le panneau de sélection
3. Vous verrez deux options :
   - **Version Énergique** (Jaune & Rouge)
   - **Version Premium** (Or & Bleu Nuit)
4. Cliquez sur l'une ou l'autre pour changer instantanément le design
5. Votre choix est sauvegardé automatiquement !
